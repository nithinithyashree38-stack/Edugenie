# EduGenie - Google Gemini Powered Learning Assistant

EduGenie is an AI-powered learning assistant built with Google Gemini that helps students with personalized study plans, doubt clearing, and smart notes generation.

### ✨ Features
- **Doubt Solver:** Ask any subject doubt and get instant, simple explanation
- **Smart Notes Generator:** Enter any topic and get well-structured notes
- **Personalized Study Planner:** AI creates a study timetable based on your goal
- **Multi-language Support:** English & Tamil

### 🛠️ Tech Stack
- **AI Model:** Google Gemini 1.5 Flash API
- **Frontend:** Streamlit
- **Backend:** Python (app.py), Java (app.java), JavaScript (javascript.js)
- **Libraries:** `google-generativeai`, `python-dotenv`
